VPS для 1С выбирают прежде всего по частоте одного ядра: платформа выполняет операции последовательно, поэтому 5,1 ГГц на четырёх ядрах закрывает задачу лучше, чем 2,2 ГГц на восьми. Вопросы и ответы

Какой сервер нужен для 1С?

С высокой частотой одного ядра и памятью по числу пользователей: от 4 ГБ для небольшой базы. Платформа однопоточна, поэтому частота важнее числа ядер.

Сколько ядер нужно для 1С?

Меньше, чем кажется: важнее частота. Четыре быстрых ядра на 5,1 ГГц обычно обгоняют восемь медленных на 2,2 ГГц.

Нужны ли лицензии для удалённого доступа?

Для терминального доступа к Windows нужны лицензии на подключения: часто две входят, каждая дополнительная около 1 200 ₽ в месяц.
